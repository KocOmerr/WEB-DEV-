# Fitness Center Management System

Bu proje, bir spor salonu (Fitness Center) için geliştirilmiş **ASP.NET Core MVC tabanlı** bir yönetim sistemidir.  
Sistem, admin paneli üzerinden spor salonu, antrenör, hizmet ve randevu yönetimini sağlamaktadır.

## 🚀 Kullanılan Teknolojiler
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQL Server (LocalDB)
- ASP.NET Core Identity
- Razor View Engine
- Bootstrap

---

## 📌 Proje Özellikleri

### 🏋️ Gym Yönetimi
- Spor salonu ekleme
- Spor salonlarını listeleme
- Açılış / kapanış saatleri yönetimi

### 🧑‍🏫 Trainer Yönetimi
- Antrenör ekleme
- Antrenörleri listeleme
- Antrenör–Gym ilişkisi

### 🛠️ Service Yönetimi
- Hizmet ekleme (PT, Yoga, Crossfit vb.)
- Süre ve ücret bilgisi

### 📅 Appointment (Randevu) Yönetimi
- Kullanıcıların randevularının listelenmesi
- Trainer ve Service ilişkileri

### 🔐 Admin Panel
- Area yapısı kullanılarak Admin panel ayrımı
- MVC mimarisine uygun controller ve view yapısı
